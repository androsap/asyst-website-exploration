## Migration from Asyst-Website v1 Source Code Repository (GitLab)

This Asyst-Website source code has been cloned from [Asyst-Website v1 Source Code Repository (GitLab)](https://gitlab.com/asyst-dev/asyst-dev-php/asyst-web) to [Asyst-Website v1 Source Code Repository (GitHub)](https://github.com/asyst-git/asyst-web/tree/master-v1).

The Git repository has been migrated using these commands:

```sh
## Create an empty branch:
git switch --orphan main
vi README.md
git commit --allow-empty -m "Initial commit on new v2 main/master branch"
git push -u origin main
```

The old branch for Asyst-Website v1.x maintenance is the `master-v1` branch.

The new default branch for Asyst-Website v2.x development is the `main` branch ([https://github.com/asyst-git/asyst-web](https://github.com/asyst-git/asyst-web)).
